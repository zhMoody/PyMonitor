# PyMonitor for macOS

一款轻量、现代的 macOS 菜单栏应用，使用 SwiftUI 构建，旨在同时监控和管理多个 Python 脚本的运行。

它非常适合需要运行长耗时任务、后台作业或多个脚本，并希望在不占用终端的情况下直观地查看其实时输出的开发者、数据科学家或爱好者。

![App Screenshot](<./Doc/py.png>)

*主界面展示了多个正在运行和已完成的脚本。*

---

## ✨ 核心功能

*   **多脚本监控 (Multi-Script Monitoring):** 可以同时启动和监控任意数量的脚本，每个脚本都在一个独立的、互不干扰的进程中运行。
*   **实时输出流 (Real-time Output Streaming):** 每个脚本的标准输出（stdout）和标准错误（stderr）都会被实时捕获并显示在对应的输出面板中。
*   **可折叠的输出面板 (Collapsible Output Panels):** 为了节省屏幕空间，每个脚本的实时输出区域都可以轻松地折叠和展开。
*   **独立的进程管理 (Isolated Process Management):** 每个脚本都拥有自己独立的生命周期管理，可以单独启动、停止或从监控列表中清除。
*   **可配置的环境 (Configurable Environment):**
    *   **自定义 Python 解释器:** 轻松指定任何版本的 Python 解释器路径 (例如 `/usr/bin/python3`, `/opt/homebrew/bin/python3`, 或虚拟环境中的解释器)。
    *   **动态脚本文件夹:** 只需选择一个包含 `.py` 文件的文件夹，应用会自动扫描并列出所有可执行的脚本。
*   **状态指示 (Visual Status Indicators):** 通过直观的颜色指示灯（🟢 运行中, 🔴 已停止, ⚫️ 待机）快速了解每个脚本的当前状态。
*   **原生 SwiftUI 界面 (Native SwiftUI Interface):** 完全使用 SwiftUI 构建，提供流畅、美观且符合 macOS 风格的用户体验。

## 🚀 开始使用

### 先决条件

*   macOS Ventura (14.0) 或更高版本
*   Xcode 14 或更高版本

### 安装与运行

1.  将本项目代码下载或克隆到你的本地机器。
2.  使用 Xcode 打开 `.xcodeproj` 文件。
3.  不需要额外配置，直接点击 Xcode 工具栏上的 `▶` (Run) 按钮进行编译和运行。
4.  应用启动后，你会在屏幕顶部的菜单栏中看到一个新的 `􀪦` (终端) 图标。

---

## 📖 如何操作

1.  **首次配置:**
    *   点击菜单栏的应用图标，打开主界面。
    *   点击右上角的 **齿轮⚙️图标** 进入设置页面。
    *   **设置解释器路径:** 输入你希望使用的 Python 解释器的完整路径。
    *   **选择脚本目录:** 点击“选择文件夹...”按钮，选择一个包含你 `.py` 脚本的文件夹。

2.  **启动脚本:**
    *   回到主界面，顶部的下拉菜单现在会显示你文件夹中所有的 Python 脚本。
    *   选择一个你想要运行的脚本。
    *   点击 **“启动新脚本”** 按钮。

3.  **监控与交互:**
    *   每启动一个脚本，下方就会出现一个新的监控面板。
    *   **查看状态:** 面板左侧的指示灯会显示脚本的当前状态。
    *   **折叠/展开输出:** 点击面板的标题区域（脚本名称部分）可以展开或收起实时输出视图。
    *   **停止脚本:** 对于正在运行的脚本，点击右侧的 **“停止”** 按钮来终止它。
    *   **清除面板:** 对于已经停止的脚本，点击 **“清除”** 按钮将其从监控列表中移除。

4.  **退出应用:**
    *   点击主界面最下方的 **“退出应用”** 按钮。
